# Daily Notes

## 1. 我希望能做到什么

> 一个普通的日常学习记录仓库。

有时候我只是想记录一下当前学到了什么，渐渐地有了什么样的进步——很多时候刚学到的东西（即使是经过多方文档的交叉验证和 AI 的帮助）往往不足以成熟到可以加入成熟的知识库，所以创建了这个仓库将学到的可能有价值的东西都一股脑写进去。

还有另一个原因就是，我每天都会学到不同的杂乱的东西，要都放到个人知识库的 Inbox 里总是会给我很大的整理压力。

---

## 2. 一些规范

这个仓库的组织架构就是简单的 `年 / 月 / 日`。

```markdown
Year
  - Month
    - Day
	- Day
	...
  - Month
    ...
...
```

在每日的记录文件里，我会使用简单的二级标题分点记录，此外不设置任何约束。

```markdown
## 1. 学习到的某个点

正文是这样的，这就是正文。当然这也是正文——正文正文正文、正文。

---

## 2. 学习到的另一个点

如果有一天，我是说如果，这不是正文的内容了，当然那不可能。
...
```
