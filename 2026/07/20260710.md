   1. 处理一连串**有规律的字符串输入**，判断所有字符串中的字符总数：

      ```python
      # 字符串输入如下，比如输入50个有规律的字符串，如何处理
      AB
      ABBC
      AABBCC
      AABBBCCCC
      AAABBBCCCCCCCC
      AAABBBCCCCCCCCCCCCCCCC
      AAAABBBBC……
      ```

      ```python
      n = 50  # 要处理的字符串个数
      
      total = 0          # 总字符数
      b_threshold = 1    # 用来计算 B 的个数，即当前需要达到的三角数
      b_count = 0        # 当前 B 的个数
      
      for i in range(1, n + 1):
          # 1. A 的数量
          a_count = (i + 1) // 2
      
          # 2. B 的数量：利用三角数递增规则
          # 当 i 超过当前三角数时，B 的数量加 1
          while i > b_threshold:
              b_count += 1
              b_threshold += (b_count + 1)  # 下一个三角数
          b_count_i = b_count
      
          # 3. C 的数量
          if i == 1:
              c_count = 0
          else:
              c_count = 2 ** (i - 2)
      
          # 当前字符串长度
          length = a_count + b_count_i + c_count
          total += length
      
      print("总字符数 =", total)
      ```

   2. [239. 滑动窗口最大值](https://leetcode.cn/problems/sliding-window-maximum/)：这个没完整写出来，因为面试官要求队列，所以只说了一下大概的思路，其实我觉得直接覆写环形数组缓冲区更简单快捷，基本是常数时间。

      ```python
      class Solution:
          def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
              ans = [0] * (len(nums) - k + 1)  # 窗口个数
              q = deque()  # 双端队列
      
              for i, x in enumerate(nums):
                  # 1. 右边入
                  while q and nums[q[-1]] <= x:
                      q.pop()  # 维护 q 的单调性
                  q.append(i)  # 保存的是下标，这样下面可以判断队首是否离开窗口
      
                  # 2. 左边出
                  left = i - k + 1  # 窗口左端点
                  if q[0] < left:  # 队首离开窗口
                      q.popleft()
      
                  # 3. 在窗口左端点处记录答案
                  if left >= 0:
                      # 由于队首到队尾单调递减，所以窗口最大值就在队首
                      ans[left] = nums[q[0]]
      
              return ans
      ```

   4. [21. 合并两个有序链表](https://leetcode.cn/problems/merge-two-sorted-lists/)

      ```python
      class ListNode:
          def __init__(self, val=0, next=None):
              self.val = val
              self.next = next
      
      class Solution:
          def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
              if list1 is None:
                  return list2
              if list2 is None:
                  return list1
              elif list1.val < list2.val:
                  list1.next = self.mergeTwoLists(list1.next, list2)
                  return list1
              else:
                  list2.next = self.mergeTwoLists(list1, list2.next)
                  return list2
      ```

   5. [102. 二叉树的层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/)

      ```python
      class Solution:
          def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
              if root is None:
                  return []
              ans = []
              q = deque([root])
              while q:
                  vals = []
                  for _ in range(len(q)):
                      node = q.popleft()
                      vals.append(node.val)
                      if node.left:  q.append(node.left)
                      if node.right: q.append(node.right)
                  ans.append(vals)
              return ans
      ```

8. 一道场景题 —— 如果被安排做一个翻译软件，你会怎么评估翻译质量的好坏：首先我根据 “信达雅” 的原则分了以下几类指标：

   1. **准确度**：通过与已有的优质翻译（如文史哲名著、影响力大的论文）对照，使用一定的技术手段（如切片然后比对稠密向量、基于神经网络的语义相似度之类的，具体实现可以查阅开源项目或论文），挑选出翻译错误的词、句、段，按事先确定好的权重加权平均出一个准确度。
   2. **流畅度**：把译文丢给一个预训练的语言模型，看模型觉得这句话顺不顺。困惑度越低，说明句子越自然。检查译文是否生硬直译（比如英文长句拆成中文时，是否用了太多 “的、了、和”）。可以建立一个中文常用搭配库，用正则或统计方法检测搭配不当。
   3. **优雅度**：比如全文中 “Deep Learning” 不能一会深度学习一会深层次学习。可以用术语库强制校验，不一致则扣分。新闻稿、法律文书、电商商品描述的口吻完全不同。可以针对不同场景训练分类器，通常需要抽样人工评估。
