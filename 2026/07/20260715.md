   1. **k 个一组反转链表**：这个在 Hot 100 里面，准备的时候刷到了，很轻松就写出来了。但是由于没有处理输入输出，可能面试官有点扣分？

      ```python
      class ListNode:
          def __init__(self, value=0, next=None):
              self.value = value
              self.next = next
              
      class Solution:
          def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
              # 剪枝
              if k <= 1:
                  return head
              
              # 计数
              n = 0
              cur = head
              while cur:
                  n += 1
                  cur = cur.next
                  
              # 1.反转长度为 k 的子链表
              # 2.将子链表的头接上前一段的尾，子链表的尾接上后一段未处理的头
              pre_tail = dummy = ListNode(next=head)
              pre = None
              cur = head
              while n >= k:
                  n -= k
                  for _ in range(k):
                      nxt = cur.next
                      cur.next = pre
                      pre = cur
                      cur = nxt
                  nxt_pre_tail = pre_tail.next
                  pre_tail.next = pre
                  nxt_pre_tail.next = cur
                  pre_tail = nxt_pre_tail
                  
              return dummy.next
      ```

      接下来问了应该如何**对这个题展开测试**：

      - 正常情况：比如 1->2->3->4->5，k=2，是否正确反转为 2->1->4->3->5？
      - 极端情况：比如 k / 链表长度两方各自非常大/非常小？
      - 特殊情况：k 和链表长度相等，k 大于链表长度、k = 1等情况。

4. **了解数据库的索引吗？**：

   我回答 MySQL 使用 B+ 树作为底层的数据结构，索引存储在叶子节点中、PostgreSQL 使用 B 树 + 根堆作为底层的数据结构，索引储存在根堆中。这两种树高低、使用索引可以减少磁盘 IO。

   索引是优化查询速度的重要环节，比如建表时使用的主键就是一种索引，根据主键进行查询速度会很快；而优化索引则是根据平时对数据的查询目标去建立新的索引，比如上述提到的查询班级怎么怎么样，如果是经常性的操作，可以对班级这一字段新建索引，就能优化查询速度。同时如果有 WHERE 使用到多字段的查询，覆盖索引可以减少回表次数。

   具体实际使用可以用 `INDEX` `EXPLAIN` 语句之类的，这点说的不是很清楚。

5. **了解 Redis 和数据库的区别吗？**：

   我回答 Redis 是加载在内存里的缓存，查询速度快于通过 ORM、SQL 裸查数据库，能容纳的并发量也高于数据库，但是容易出现缓存不一致的情况，需要通过多方同步和双删来保证数据一致性。基于速度优先的原则，如果设置了 Redis，就应该先查 Redis，如果查不到缓存就应该查询数据库。这里感觉回答的不是很多。
